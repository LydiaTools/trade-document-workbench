# Trade Document Workbench

**一份订单，少填几遍。装箱对不上，先看清差在哪。**

客户改了数量，你要回头改报价单、PI、合同和商业发票；工厂发来装箱表，又得重新核对型号、件数和箱数。

单证工作台把这些工作放在同一个本地页面里：订单资料填一处，切换查看五种单据；实际装箱单独记录，再与订单逐项核对。常用产品、客户和历史版本留在当前浏览器，下次接着用。

## 先完成一张订单

1. 打开[在线工作台](https://lydiatools.github.io/trade-document-workbench/)，或下载离线 HTML，填写卖方资料，选择或补充客户。
2. 从产品库添加产品，检查数量、单价和贸易条款。
3. 切换报价单、形式发票、销售合同、商业发票和装箱单，查看同一份订单的数据。
4. 填写装箱资料，完成出单检查，再导出单份 PDF，或把五份 PDF 打包为 ZIP。
5. 保存历史版本；返单时复制成新订单，定期下载完整备份。

单文件已经包含样式、脚本和依赖库，无需注册、安装依赖或填写 API Key。初始订单与产品是演示填充值。

需要通过本地地址打开时，在仓库根目录运行：

```sh
python3 -m http.server 8769 --bind 127.0.0.1 --directory src
```

然后访问 <http://127.0.0.1:8769/>。这只在当前电脑提供页面。

## 按你正在做的事选功能

| 你正在遇到的事 | 在这里怎么做 |
| --- | --- |
| 同一订单要重复填写多张单据 | 共用订单资料，切换五种单据预览与导出 |
| 产品和客户每次都要重新录入 | 保存产品库、客户库，也可通过 CSV 导入产品资料 |
| 工厂的装箱表和订单对不上 | 导入 CSV 或粘贴 Excel / WPS 表格，按型号核对已装数量 |
| 一箱有多个型号，箱数和重量容易重复加 | 用实际装箱记录表达混装箱，物理箱数、重量和体积只统计一次 |
| 客户返单，想沿用上一次资料 | 从历史版本复制为新订单，再修改本次内容 |
| 要换浏览器或换电脑继续做 | 先下载完整 JSON 备份，再在目标工作区恢复 |

## 尾箱、混装，别重复算一遍

订单数量和实际装箱分开保存。改了订单，不会悄悄改掉工厂已经填好的装箱记录。

例如：A 型号 25 件、B 型号 13 件，分别装满 24 件和 12 件，剩下各 1 件放进同一个尾箱。实际是 **3 箱**，混装尾箱的箱数、重量和体积只算一次。

如果出现少装、多装、箱号重叠、订单外产品，或同一组箱号的重量尺寸不一致，工作台会指出具体差异。装箱不一致时，装箱单和整套 PDF 导出会被拦住；报价仍可继续整理。

## 做好的单据，也要能接着改

- 五种单据共用订单资料；自由填写的条款和产品文字保留原文。
- 单据可选中文、英文或中英双语，并提供九种配色。
- 单价支持最多四位小数，金额逐行四舍五入后汇总；切换币种不会换算汇率。
- 导出单份 PDF，或包含五份 PDF 的 ZIP；PDF 文字以图像呈现。
- 数据保存在当前浏览器的 localStorage。不同浏览器和访问地址的工作区彼此独立，完整备份用于迁移和恢复。

当前版本不含云协作、OCR、自动翻译、海关申报或三维装柜功能。
